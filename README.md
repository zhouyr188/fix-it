# 🔧 Fix It — 你的口袋英语批改员

> **Fix yourself. Become a brand-new you.**

中译英练习 + AI 批改 + 错题怪兽对战。为备考四六级/雅思、想真正消灭「惯犯错误」的学生做的碎片时间纠错工具。

## 它解决什么问题

背了模板、刷了真题，翻译里的错误却总是同一批：时态溜了、中式直译、词形乱变。**Fix It 不练新题海，专打你的旧错题**——每犯一次错，就多一头「怪兽」被关进基因库；答对一个毕业一个，怪兽消灭出库。

## 功能

- 📝 **交作业**：AI 出中译英题（难度三档：🌱基础/🌿中等/🌳进阶，机械规格控制句长与从句数）
- ✅ **AI 批改**：A/B/C/D 评级 + 最小改对版 + 地道升级版
- 🧬 **惯犯基因库**：错题按 时态/直译/词形 三类关押，简历式卡片
- ⚔️ **怪兽对战**：挑战一头「错误类型怪兽」，战题从你自己的错题库抽取——答对掉血、答错满血复活、连对三次消灭出库
- 🌟 好句墙：批改完收藏升级版好句，睡前翻墙复习（背熟了可撤下）
- 📦 搬家公司：错题+好句一键打包导出/导入，换设备数据不丢
- 📅 打卡墙：每天交满 3 题自动亮灯，月历+连续天数可视化
- 📏 **规格验收**：机器自动数词数，训练对句子长度的手感

## 怎么玩

**【交作业】** 出新题后左上角标注难度（四级至雅思水平），将答案填入框中，检查完即可提交。AI 老师批改并评分，基于你的回答给出改对版和升级版，指出你的惯犯类型，错题自动存入错题档案。每天交满 3 题，当日打卡自动点亮。

**【错题档案】** 内关押着你的惯犯类型。点击挑战，输入答案后向怪兽挥刀——怪兽消失的同时，你的这类错误也随之消失。

**【好句墙】** 觉得 AI 出的题不错，批改完点击「🌟收藏好句」。背熟了就点🗑️撤下。

**【搬家公司】** 换设备时点击「打包我的全部家当」下载成文件，新设备把文件内容贴进「搬进新家」即可同步。

## 技术栈

React Native (Expo) + 智谱 GLM-4-Flash · AsyncStorage 本地存储 · Animated 动画

出题质量不靠 AI 自觉：AI 按「题目/译文」两行交卷，**难度三档由话题与思维深度分层**，不达标自动带原因退货重造（最多 3 次）——规格执法，而不是许愿。
