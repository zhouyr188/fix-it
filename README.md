# 🔧 Fix It — 你的口袋英语批改员

> **Fix yourself. Become a brand-new you.**

中译英练习 + AI 批改 + 错题怪兽对战。为备考四六级/雅思、想真正消灭「惯犯错误」的学生做的碎片时间纠错工具。

## 它解决什么问题

背了模板、刷了真题，翻译里的错误却总是同一批：时态溜了、中式直译、词形乱变。**Fix It 不练新题海，专打你的旧错题**——每犯一次错，就多一头「怪兽」被关进基因库；连对三次，怪兽消灭出库。

## 功能

- 📝 **交作业**：AI 出中译英题（难度三档：🌱基础/🌿中等/🌳进阶，机械规格控制句长与从句数）
- ✅ **AI 批改**：A/B/C/D 评级 + 最小改对版 + 地道升级版
- 🧬 **惯犯基因库**：错题按 时态/直译/词形 三类关押，简历式卡片
- ⚔️ **怪兽对战**：挑战一头「错误类型怪兽」，战题从你自己的错题库抽取——答对掉血、答错满血复活、连对三次消灭出库
- 📏 **规格验收**：机器自动数词数，训练对句子长度的手感

## 技术栈

React Native (Expo) + 智谱 GLM-4-Flash · AsyncStorage 本地存储 · Animated 动画

出题质量不靠 AI 自觉：AI 按「题目/译文」两行交卷，**机器亲手数词数与汉字数**，不达标自动带原因退货重造（最多 3 次）——规格执法，而不是许愿。

```bash
npm install
echo "ZHIPU_API_KEY=你的key" > .env
npx expo start
```
